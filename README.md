# Fake News Detection

> NLP-based binary classifier to detect misinformation in news articles.

## Overview
Fine-tuned a text classification pipeline on labeled news datasets to distinguish credible articles from misinformation. Explored both classical ML (TF-IDF + Logistic Regression) and deep learning approaches.

## Features
- Text preprocessing: tokenization, stopword removal, stemming
- Feature extraction: TF-IDF, word embeddings
- Models compared: Naive Bayes, Logistic Regression, LSTM
- Visualizations: confusion matrix, word clouds by label

## Tech stack
`Python` `scikit-learn` `NLTK` `TensorFlow` `pandas` `matplotlib`
